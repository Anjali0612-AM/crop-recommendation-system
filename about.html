ℹ️ About Crop Recommendation System

Machine Learning Based Agriculture Project

🌱 About the Project

The Crop Recommendation System is a machine learning based application that recommends a suitable crop based on soil and environmental conditions.

📊 Input Parameters

  • Nitrogen (N)
  • Phosphorus (P)
  • Potassium (K)
  • Temperature
  • Humidity
  • pH Value
  • Rainfall

🤖 How It Works

The user enters soil and environmental values. The trained machine learning model processes these values and predicts a suitable crop.

🌾 Features

  • Crop recommendation
  • Crop climate information
  • Water requirement information
  • Season information
  • Input value validation
  • Prediction history

🎓 Project Purpose

This project demonstrates the practical use of Python, Machine Learning, Pandas and Flask in an agriculture-related application.
